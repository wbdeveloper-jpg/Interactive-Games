# Suggested Replacement Artwork Sizes

The package does not include generated artwork. Its Editor tool builds simple
coloured Unity UI Image placeholders in the current scene.

If custom images are added later, these source sizes are recommended:

| Artwork | Suggested source size | Notes |
| --- | ---: | --- |
| Landscape background | 1920 x 1080 px | Full-screen, opaque |
| Traditional scale group | 1100 x 650 px | Transparent PNG |
| Scale object | 300 x 180 px | Transparent PNG |
| Graduated 2 L beaker | 420 x 580 px | Transparent PNG; keep the centre clear |
| Tap controls group | 430 x 420 px | Transparent PNG |
| Small weight token | 256 x 160 px | Transparent PNG |
| Large weight token | 256 x 160 px | Transparent PNG |
| Result decoration | 700 x 470 px | Optional transparent PNG |

The functional water fill and hidden Hint target line should remain separate UI
Images under the existing mask when custom beaker artwork is used.

No image-generation step is required.
