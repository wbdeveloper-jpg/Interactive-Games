# Guess Who I Am - Developer / AI Handoff

Last updated: 2026-06-24

This file is for the next Unity developer or AI that continues the game. It captures the current design, code architecture, UX decisions, package history, and the latest safe update rules.

## 1. Current Project Summary

Game name: **Guess Who I Am**

Pattern: **Progressive clue-based quiz**.

Player sees 3 clues and guesses the answer from 3 or 4 options. Clue 1 is available first. Clue 2 and Clue 3 are locked. Revealing more clues lowers the points earned for a correct answer.

Target orientation: **Landscape mobile UI**.

Visual style: child-friendly, polished, purple/yellow game UI, large buttons, near-square clue cards, right-side guide/mascot panel, minimal text.

Final content direction: **Class 3-4 level simple questions**, mostly animals, fruits, vegetables, and school/home objects. Avoid hard content such as freedom fighters for this version. Current guide-image example uses **Mango**.

## 7. Current UI Layout Rules

### Gameplay Screen

- Landscape gameplay only.
- No gameplay title text on the main quiz UI.
- Thin top HUD, but current allowed height is around 65-75 px.
- Main left area has clue cards on top and answer options below.
- Right side has fixed-width guide/mascot/action panel.
- No separate bottom feedback bar. Use speech bubble in the guide panel.
- No unnecessary question image space in gameplay UI.

### Top HUD

- Score block was removed from visible HUD to keep it clean.
- Center: `Question 2 / 10` text and slim progress line with markers.
- Right: compact coin block, help button, pause button.
- Progress supports 10 questions cleanly.

### Left Main Area

- Top section: 3 clue cards in one horizontal row.
- Bottom section: answer buttons in 2x2 grid.
- Clue section target is roughly 55 percent of left gameplay height.
- Options section target is roughly 45 percent.

### Clue Cards

Current final clue UX:

- Clue 1 active by default and gives +10.
- Clue 2 locked by default; opening it makes current answer value +7.
- Clue 3 locked by default; opening it makes current answer value +5.
- Active card is bright white.
- Already revealed but non-active cards are dull white.
- Locked cards are dim purple.
- Open clue cards are now **read-only**. Clicking an already-open clue does nothing.
- Reason: If Clue 3 is open and user clicks Clue 1, it must not visually imply they can get +10 again.
- Tapping the next locked clue works as reveal:
  - Clue 1 open -> tap locked Clue 2 -> reveals Clue 2.
  - Clue 2 open -> tap locked Clue 3 -> reveals Clue 3.
- Tapping Clue 3 before Clue 2 gives only visual hint: shake tapped clue and pulse required clue/reveal button.
- No popup should be added for blocked clue tap unless user asks; current version uses animation only.

### Clue Reveal Animation

- Reveal uses DOTween spin + pop animation.
- Works both from Reveal Next Clue button and tapping the next locked clue.
- Inspector fields:
  - `Use Clue Reveal Spin Animation`
  - `Clue Reveal Spin Duration`
  - `Clue Reveal Pop Scale`
  - `Clue Reveal Spin Turns`

### Answer Options

- 4 answer buttons in 2x2 grid.
- Supports 3 or 4 options by Inspector setting.
- Button height is capped in responsive script to prevent tablet stretching.
- Current max height is controlled by `GuessWhoIAmResponsiveLayout`:
  - `Min Option Button Height`
  - `Max Option Button Height`
  - `Max Tablet Option Width`

### Right Guide Panel

- Fixed width with min/preferred/max width.
- Mascot area uses blank white placeholder sprite/image in generated UI.
- Preserve aspect ratio for mascot/guide graphics.
- Speech bubble below mascot.
- Reveal Next Clue button below speech bubble.
- Next Question button below reveal button.
- Speech bubble, reveal button, and next button heights were capped to avoid 270 px tall blocks.
- Alignment is lower-center so mascot has usable space.

## 10. Gameplay Flow

Runtime sequence in latest manager:

1. `Awake()` registers listeners and finds audio manager if missing.
2. `Start()` prepares panels.
3. If `startRoundOnPlay` is true, `StartupFlowRoutine()` begins.
4. Bloom pre-game opens if enabled.
5. Game waits for `RewardManager.Instance.IsPreGameComplete`.
6. Loading panel runs.
7. How-to panel opens.
8. When Start/Continue is clicked, `StartNewRound()` begins gameplay.
9. Questions are randomly selected from database.
10. Options are randomized.
11. Player answers or reveals clues.
12. After each answer, Next button appears and auto-next slider runs.
13. After final question, local result panel opens.
14. Player clicks Continue.
15. Bloom post-game opens.

## 11. Scoring Rules

Default values:

```text
Clue 1 answer = +10
Clue 2 answer = +7
Clue 3 answer = +5
```

Important implementation detail:

- Current points are based on `revealedClueCount`, not by clicking back to a previous clue.
- `selectedClueIndex` is visual only and represents the latest active scoring clue.
- Already-open cards are read-only to prevent wrong expectation.

Answer behavior:

- Correct:
  - add current clue points,
  - disable options,
  - keep only already revealed clues visible,
  - show Next button,
  - optional points popup appears if prefab assigned.
- Wrong:
  - disable options,
  - reveal all clues,
  - highlight correct answer,
  - show Next button.

User setup steps:

1. In Canvas, create a `TextMeshProUGUI` object.
2. Set preview text to `+10`.
3. Make it large, bold, bright, and non-blocking.
4. Disable Raycast Target.
5. Drag it into Project to create a prefab.
6. Delete/disable the scene preview object.
7. Assign prefab to `Points Popup Text Prefab` on `GuessWhoIAm_GameManager`.
8. Optional: create an empty RectTransform under Canvas named `PointsPopupParent` and assign it.

If no prefab is assigned, the game works normally with no popup.

## 13. Bloom Reward Integration

Manager implements:

```csharp
IGameSceneCallbacks
IGameAudioCallbacks
```

Current Bloom flow:

- Pre-game: `RewardManager.Instance.ShowPreGame(bloomSkills)`.
- Wait: `RewardManager.Instance.IsPreGameComplete`.
- Post-game: local result panel first, then Continue button calls `ShowPostGame`.

Current Bloom skill fields:

- `primaryBloomSkill = Remember`
- `primaryBloomMaxScore = 100`
- `secondaryBloomSkill = Understand`
- `secondaryBloomMaxScore = 50`
- `useCustomBloomWeights`
- `bloomTimeWeight`
- `bloomAccuracyWeight`
- `expectedMaxTime`

Evaluation data:

```csharp
timeScore = Mathf.Clamp01(1f - (timeTaken / expectedMaxTime));
accuracyScore = correctCount / totalQuestionCount;
mistakeCount = mistakeCount;
timeTaken = timeTaken;
```

Callbacks:

```csharp
OnPlayAgain() -> reload active scene
OnHome() -> load homeSceneName, default "Loader Scene"
OnRewardScreenOpen() -> stop game BGM
```
